# Zulzaga School Site

Сум/дүүргийн ерөнхий боловсролын сургуулиудын нэгдсэн вэбсайт. Нэг код олон сургуульд: орж ирсэн домэйноор аль сум, аль сургууль болохыг танина.

- Нийтийн сайт: нүүр, сургууль бүрийн хуудас, мэдээ, хичээлийн жил, багш нар, элсэлт, ил тод байдал, холбоо барих (санал хүсэлт)
- `/admin` — сумын админ (бүх сургууль) эсвэл сургуулийн админ (зөвхөн өөрийнх)
- Zulzaga EDU-тэй холих**гүй** — тусдаа repo, тусдаа DB. «Сурагч / Эцэг эхийн булан» зөвхөн EDU руу холбоос.

## Ажиллуулах
```
npm install
npm run dev          # http://localhost:3100, DATABASE_URL байхгүй бол .data/ дахь PGlite + демо өгөгдөл
node scripts/e2e.mjs # бүтэн урсгалын шалгалт (Edge headless)
```
Демо нэвтрэлт: `sum` / `school1..4`, нууц үг `DEMO_PASSWORD` (анхдагч `demo2026`).

## Орчны хувьсагч
| | |
|---|---|
| `DATABASE_URL` | Postgres. Хүснэгтүүд асахад автоматаар үүснэ (src/lib/sql.ts) |
| `SESSION_SECRET` | Прод дээр заавал |
| `SEED_DEMO=0` | Хоосон DB-д демо өгөгдөл ҮҮСГЭХГҮЙ (анхдагч: үүсгэнэ) |
| `DEFAULT_ORG` | Танигдаагүй домэйнд харуулах сум (анхдагч `zamyn-uud`) |
| `ROOT_DOMAIN` | `<сум>.ROOT_DOMAIN` дэд домэйн |
| `CNAME_TARGET` | Админы «Домэйн» хуудсанд харуулах CNAME хаяг |

## Домэйн
Сургууль домэйноо `/admin/domain`-д бүртгэж, DNS-дээ CNAME → `CNAME_TARGET` нэмнэ. Hosting талд (Railway) custom domain нэмнэ.
